# Design Docs

Welcome to the design documentation for the MARS/WARS robotics team! These docs cover how we design robot parts and how
we manufacture them in our shop.

## Design Guide

Best practices for designing parts that are strong, light, and easy to build.

- [Onshape Practices](./design_guide/onshape): How we structure, version, and model robots in Onshape.
- [COTS Parts & Suppliers](./design_guide/suppliers): Where we buy parts, and getting them into Onshape.
- [Materials](./design_guide/materials): Stock materials and hardware, and where to use each.
- [Lightweighting](./design_guide/lightweighting): Techniques for removing weight without losing strength.

## Design Reference

- [Game Challenges](./reference/game): Past game pieces and endgames, with the robots that handled them best. Start
  here when a new game is released.
- [Common Mechanisms](./reference/mechanisms): How intakes, shooters, elevators, arms, grabbers, and climbers work,
  with Behind the Bumpers videos and tech binders to study.

## Mechanical

How to safely turn a design into a real part.

- [Shop Safety](./mechanical/machining/safety): Required reading before working in the shop.
- [Machining](./mechanical/machining): Operating guides for the CNC mill, CNC router, and lathe.
- [CAM](./mechanical/cam): Generating G-code in Fusion, plus our tool and work offset reference.
- [3D Printing](./mechanical/3d_printing): Taking a part from Onshape to a finished print.

:::tip New to design?
Start with [Shop Safety](./mechanical/machining/safety), then get set up with [Fusion](./mechanical/cam/fusion-sign-up).
:::
