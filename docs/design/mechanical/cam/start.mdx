This guide walks you through setting up a part and generating G-code in Fusion. If you do not have access to Fusion or
the shared workspace, see [Fusion Sign-Up](./fusion-sign-up) first.

## Exporting from Onshape to Fusion

1. Right click the part in the Onshape model or part tree and click **Export**.

    <img src={onshape_export} width="800" alt="Export option in Onshape"/>

2. Confirm the part has a descriptive name (see [Naming Conventions](../../design_guide/naming)):
    - Subassembly
    - Part name
    - Date of export
3. Set **Format** to **STEP** and **Option** to **Download**.

    <img src={onshape_download} width="400" alt="Onshape export dialog"/>

4. Open Autodesk Fusion and open the **Data Panel** in the upper left corner.
5. Select the season's project folder (for example, **2026FRC4143**).

    <img src={Upload_1} width="400" alt="Fusion Data Panel project list"/>

6. Navigate to the subassembly folder.

    <img src={Upload_2} width="400" alt="Subassembly folder in the Data Panel"/>

7. Click **Upload** in the Data Panel, drag the exported STEP file into the upload window, and click **Upload**.
8. Once the file is uploaded, double click the part to open it in Fusion.

    <img src={Upload_3} width="400" alt="Uploaded part in the Data Panel"/>

## Fusion CAM Setup

1. Align the part in the Fusion workspace.
    - Identify the top, front, and right faces of the part.
    - Use the **Align** tool to set the orientation of the part onto the XY plane.
2. Switch to the **Manufacture** workspace.
3. Click the **Setup** dropdown and select **New Setup**.
