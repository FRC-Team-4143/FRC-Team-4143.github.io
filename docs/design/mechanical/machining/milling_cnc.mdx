Computer numerical control (CNC) milling is a form of [milling](./milling_manual) where the machine's movements are
controlled by a program (G-code) instead of by hand.

## CNC Mill Safety

A CNC mill is a dangerous piece of industrial equipment, and safety must be considered during operation. Review the
general [shop safety rules](./safety) first.

:::danger Hazards

**High Rotational Energy** (moderate risk)
- **Harm:** Lacerations.
- **Cause:** Contact with the tooling, or overextending while removing material from around the tool.
- **Prevention:** Use a brush, not your hands, to move material away from the tool. When loosening the vise, pull the
  handle toward your body, not away.

**Flying Debris** (minor risk)
- **Harm:** Minor lacerations and eye injury from metal shavings, parted-off pieces, or shattered tooling.
- **Prevention:** Always **wear safety glasses** near an operating CNC mill, and confirm the shield is in place.

**Sharp Edges** (minor risk)
- **Harm:** Minor lacerations from metal shavings, cutting surfaces, and machined edges.
- **Prevention:** Never handle metal shavings with bare hands; use cleaning tools and gloves. Sand or file machined
  parts to remove sharp edges.

:::

:::warning Gloves
**Gloves must never be worn while the CNC mill is running** due to the risk of entanglement. Only put on gloves to
handle parts once the spindle has come to a complete stop.
:::

## Machine Startup

**1. Initialize the machine.**

- Switch the **computer** ON.
- Release the **Stop** button.
- Press the **Start** button.

<img src={Panel_Start} width="600" alt="CNC mill control panel start buttons"/>

**2. Reference the axes.**

1. Press the blinking **Reset** button.
2. Press **Reference Z** and wait until motion stops.
3. Press **Reference X & Y** and wait until motion stops.

<img src={Reset} width="600" alt="Reset and reference buttons"/>

## Program Setup

To begin, load the G-code file from a flash drive prepared by the Fusion programmer.

**1. Insert the flash drive** into the USB port below the computer.

<img src={USB} width="400" alt="USB port below the CNC mill computer"/>

**2. Copy the file to the machine.**

1. Click **File**.
2. On the right side, navigate to the G-code file on the flash drive.
3. On the left side, navigate to the current year's or project's G-code folder.

<img src={Copy_1} width="400" alt="File copy screen"/>

4. Select the file and click **Copy**.
5. Double click the copied file to open it.

<img src={Copy_3} width="400" alt="Copied file in the program folder"/>

## Confirm Setup

Once the program is loaded and the material is secured, check the key parts of the program.

1. **Confirm the work offset (G##).**
    - Find the program's work offset (**G54 - G59**).
    - Confirm the material's orientation matches the Fusion setup and the G-code graphic.
    - Most programs use **G57**: left side of the vise, on top of the back parallels.
    - See [Tools & Offsets](../cam/tools#cnc-mill-work-offsets) for what each work offset means.
2. **Confirm the tool (T##).**
    - Find the program's tool number.
    - Confirm it matches the tool loaded in the spindle.
    - See [Tools & Offsets](../cam/tools#cnc-mill-tools) for tool numbers.
3. **Confirm the spindle speed and feed rate (F##).**
    - Find the program's feed rate.
    - Confirm it matches the recommended values for the loaded tool and material.
    - See [Tools & Offsets](../cam/tools#cnc-mill-tools) for feed rates.
4. **Visually inspect the toolpath.**
    - Use the G-code graphic to confirm the toolpath matches the intended design.
    - Confirm the work offset location matches the secured material.
    - Confirm the tool will not collide with the vise, clamps, or any other obstructions.

<img src={example_gcode2} width="600" alt="G-code graphic showing the toolpath"/>

## Run Program

When all setup checks are complete, the program is ready to run. Step through the start of the program and each
machining operation to check for issues.

1. Turn on single block mode by pressing **Single Block**. The green light turns on when it is active.
2. The yellow bar shows the next line of code to be run.
3. Limit the machine's speed while validating:

    | Override | What it controls | Setting during validation |
    |---|---|---|
    | **FEED** | Cutting feed rate | **20-40%** |
    | **RPM** | Spindle speed | **100%** |
    | **MAX VEL** | Speed of movements between cuts | **20-40%** |

4. Press **Cycle Start** to run the next line of code.
5. Watch the **DTG** (Distance To Go) values, which show how far the tool will travel in each axis for the current
   move. Keep stepping through the program and check whether any move will carry the tool into an obstruction.

<img src={validating_1} width="600" alt="Single block mode and DTG readout"/>

Once an operation has been validated, single block mode can be turned off and the program run at full or reduced speed.
When the program reaches a new operation, turn single block mode back on and validate the new operation before
continuing.

### Torque Monitoring

:::warning
While cutting and drilling, monitor the spindle motor torque.
- If the torque reaches the **yellow zone**, reduce the feed rate.
- If the torque reaches the **red zone** and reducing the feed rate does not help, **stop the program immediately** and
  investigate.
:::
