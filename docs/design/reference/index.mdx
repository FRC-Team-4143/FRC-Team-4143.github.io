# 🔎 Mechanism Reference

When a new game is released, the fastest way to start is to find past games with a similar game piece and study the
robots that handled it best. Each page below covers one type of game piece, with the past games that used it, the
teams worth studying, and links to their **Behind the Bumpers** videos, **tech binders**, and **CAD**.

## How to Use These References

1. **Watch the Behind the Bumpers video first.** In a few minutes, a team walks through every mechanism on the robot
   and why they built it that way.
2. **Read the tech binder** for the mechanism you care about. Binders explain the requirements, the prototypes that
   failed, and the final design.
3. **Open the CAD** to see real dimensions: roller spacing, compression, gear ratios, and materials.
4. **Read the Open Alliance build thread** if the team has one. It shows the whole season, including what didn't work.

:::tip
Look for the *requirement*, not just the mechanism. The best teams explain what their mechanism had to do (for
example, "touch it, own it"), and that is what transfers to a new game.
:::

## General Resources

- [Behind the Bumpers](https://www.youtube.com/channel/UCuJUknE5JjilAfNnmbvr22Q): Robot walkthrough videos from the
  FUN Robotics Network (FIRST Updates Now).
- [FRCDesign Mechanism Examples](https://www.frcdesign.org/mechanism-examples/): Onshape examples of common mechanisms.
- [The Open Alliance](https://www.theopenalliance.com/): Teams that share their build season publicly, listed by year.
- [FRC Tech Documents & CAD Collection](https://www.chiefdelphi.com/t/frc-tech-documents-collection-cad-collection/386723):
  A Chief Delphi collection of tech binders and CAD releases.
- [254 Cheesy Poofs robots](https://www.team254.com/first/): Each year's page links that robot's tech binder.
- [1678 Citrus Circuits CAD & code](https://www.citruscircuits.org/cad-code-release): CAD and code for each season.
- [Spectrum 3847 seasons](https://spectrum3847.org/seasons/): Build blogs for each season.
- [ReCalc](https://www.reca.lc/): Flywheel, arm, and elevator calculators.
