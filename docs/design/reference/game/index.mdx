# Game Challenges

- [Game Pieces](./pieces/index.mdx): balls, discs, boxes, cones, and tubes, with dimensions and the robots that handled

- [Endgame & Climbing](./endgame/index.mdx): hanging, climbing, and balancing at the end of the match.
