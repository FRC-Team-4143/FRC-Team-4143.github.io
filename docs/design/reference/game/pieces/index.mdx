# Game Pieces

When a new game is released, find past games with a similar game piece and study the robots that handled it best. Each
page below covers one type of game piece, with the past games that used it, the teams worth studying, and links to their
**Behind the Bumpers** videos, **tech binders**, and **CAD**.

## Find a Game Piece

| Game piece | FRC games | FTC games | Page |
|---|---|---|---|
| Small balls (fuel, power cells, cargo, artifacts) | 2006, 2009, 2010, 2012, 2017, 2020-21, 2022, 2026 | 2016-17, 2018-19, 2021-22, 2025-26 | [Small Balls](./small-balls.mdx) |
| Large balls (boulders, cargo, algae, cap balls) | 2004, 2008, 2014, 2016, 2019, 2025 | 2016-17 | [Large Balls](./large-balls.mdx) |
| Rings and discs (notes, hatch panels, gears, frisbees, pixels) | 2007, 2011, 2013, 2017, 2019, 2024 | 2020-21, 2023-24 | [Rings & Discs](./rings-discs.mdx) |
| Boxes (cubes, totes, bins, glyphs, stones, samples) | 2003, 2015, 2018, 2023 | 2017-18, 2018-19, 2019-20, 2021-22, 2024-25 | [Boxes](./boxes.mdx) |
| Cones and tetras | 2005, 2023 | 2022-23 | [Cones & Tetras](./cones.mdx) |
| Tubes (coral, recycling containers) | 2015, 2025 | | [Tubes](./tubes.mdx) |

Every game piece is tagged **FRC** or **FTC**. FTC pieces are smaller, but the mechanisms that handle them work the
same way, so they are a good source of ideas.
