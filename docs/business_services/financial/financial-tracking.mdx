# MARS/WARS Financial Tracking
Every transaction is recorded in the team's financial tracker with a **category** and a **subcategory**.

## Categories
| Income | Expense |
|---|---|
| Fundraising | Competition |
| Regrant | Marketing |
| Student Fees | Outreach |
| Misc Income | Supplies |
| | Misc Expenses |

## Subcategories
| Category | Subcategories |
|---|---|
| **Fundraising** | Donations, Pork Chop Lunch, Sponsor, Super Bowl Squares, Trivia, Vendor Fair, Misc |
| **Competition** | Fees, Hotel, Meals, Misc |
| **Marketing** | Fun Shirts, Swag, Uniforms, Misc |
| **Outreach** | Lego League, Misc |
| **Supplies** | Field, Robot, Shop |

Subcategories are written as `Category - Subcategory`, for example `Fundraising - Trivia` or `Competition - Hotel`.

## Tracker Columns
| Column | What to enter |
|---|---|
| **Date** | The transaction date (not the date you are recording it) |
| **Amount** | Income is a positive number, expenses are negative |
| **Cash/Check/CC/Shopify** | How the money was spent or received |
| **Vendor** | The vendor, for expenses |
| **Check Number** | If the team wrote an actual check, the check number for tracking |
| **Cleared** | Put an "X" here once the check has cleared the bank |
| **Account** | The team has 2 accounts: a NFP (Not for Profit) account and a school account |
| **Team** | If an expense can be assigned to a specific team, record it here; otherwise leave it blank |
| **Income/Expense** | Fills in automatically based on the amount you enter |
| **Category** | The high level income or expense category |
| **Subcategory** | The lower level category used for financial reporting |
| **Notes** | Any important notes |
