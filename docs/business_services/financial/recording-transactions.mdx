# Recording Transactions
We use **double entry accounting**: every financial transaction has two sides. Whatever happens on one side of the
books must have an equal and opposite entry somewhere else. Each entry is either a **debit** or a **credit**.

## Exercise
Record these transactions in the Cash account, then in the account on the other side of each transaction:
- Donation received: \$1,000
- Robot supplies purchased: \$500
- Fundraiser income: \$5,000
- Saturday lunch reimbursement: \$250

<details>
<summary>Answers</summary>

**Cash**

| Transaction | Debit | Credit |
|---|---|---|
| Donation Received | \$1,000 | |
| Robot Supplies Purchased | | \$500 |
| Fundraiser Income | \$5,000 | |
| Saturday Lunch Reimbursement | | \$250 |

Balance = **\$5,250**

**Fundraising**

| Transaction | Debit | Credit |
|---|---|---|
| Donation Received | | \$1,000 |
| Fundraiser Income | | \$5,000 |

**Supplies**

| Transaction | Debit | Credit |
|---|---|---|

**Saturday Meals**

| Transaction | Debit | Credit |
|---|---|---|
| Saturday Lunch Reimbursement | \$250 | |
