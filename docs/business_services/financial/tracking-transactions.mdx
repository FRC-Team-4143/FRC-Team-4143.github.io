# Tracking Transactions
Every transaction gets recorded in the team's financial tracker. Recording the same details every time makes it easy to
see where money came from, where it went, and to build reports later.

## What to Record
| Field | What to enter |
|---|---|
| **Date** | The date of the transaction (not the date you are recording it) |
| **Amount** | Income is a positive number, expenses are negative |
| **Payment method** | How the money was spent or received, such as cash, check, or card |
| **Vendor** | Who the team paid, for expenses |
| **Check number** | If the team wrote a check, the check number, so it can be matched to the bank statement |
| **Cleared** | Marked once a check has cleared the bank |
| **Category** | A high level income or expense category |
| **Subcategory** | A more specific category used for reporting |
| **Notes** | Anything important about the transaction |

## Categories
Categories group transactions so we can see the big picture.

| Income | Expenses |
|---|---|
| Fundraising | Competition |
| Sponsorships and donations | Marketing |
| Misc income | Outreach |
| | Supplies |
| | Misc expenses |

Subcategories break a category down further, written as `Category - Subcategory`. For example, `Competition - Hotel`
or `Supplies - Robot`.
