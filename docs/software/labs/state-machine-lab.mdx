# State Machine Lab
Drive the 2026 robot's super state machine one 20 ms loop at a time. Hold a button to ask for a state, then watch `handleStateTransition` pick where the robot goes, `updateLogic` ask each subsystem for a state, and each subsystem decide when it gets there. At the bottom, build a shooter's transition table yourself.
