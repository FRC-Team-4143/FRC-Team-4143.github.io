# PID Tuning Lab
Tune feedforward and PID on a simulated arm, elevator and flywheel. Start with feedforward (kG, kS, kV), add kP until the mechanism gets there quickly, and use kD only if it rings. Angles are in radians and the gains are in volts per radian or per meter, like the rest of these docs.
