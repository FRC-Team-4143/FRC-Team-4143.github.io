# Behavior Tree Lab
Watch an autonomous behavior tree drive a pretend robot, one tick at a time. The tree is drawn by Arborist, the same viewer Arbor uses for its live view, so the colours mean what they mean on the real robot. Break the camera or jam the intake, then edit the XML and run your own tree.
