# Drive Math and Methods
In this module, we will cover the concept of methods in programming and how to implement them in the context of FRC robot development. Methods are reusable blocks of code that perform specific tasks, allowing for modular and organized programming.

## Exercises
### Methods
- Write methods that turn encoder inputs into usable outputs
    - Two of them, `linearSpeed` and `angularSpeed`, you write from scratch, signature and all
    - translation position in m
    - translation speed in m/s
    - rotation speed in rad/s
- Write a method that averages an array of numbers using a `for` loop
    - Use it to smooth the robot's speed over the last 5 readings
- Write methods to set the speed of the drive motors
    - setting the left side only
    - setting the right side only
    - a method that performs the math of arcade drive and sets the sides (using the methods above)
### The IO model
- Read how the library calls `readInputs`, `writeOutputs` and `logData` every loop, and find those three steps in the drivetrain
