# The Tools
This is the first training module in our FRC programming series. It covers the software development tools you will use every time you program: Scriptum, the editor, AdvantageScope and Elastic. It opens with a few minutes of robot safety.

Most of the training happens in **Scriptum**, so the slides walk through it: the menus along the top, the **Verify** button that checks each step of a lesson, and **Dozer**, the team's plow robot, whose button in the top bar opens short walkthroughs that point at the real buttons in each tool, and who has hints when you are stuck.

:::note
This session does not cover robot hardware. The roboRIO, radio, motor controllers, the CAN bus and the tools that set them up start in the next session, [Motors and Drivetrains](./motors-drivetrains.mdx).

Git and GitHub are not in this session either. They have their own session at the end of the training, [Coding as a Team](./coding-as-a-team.mdx), once you have written some code worth saving.
:::

## Exercises
- Know what each tool is for: Scriptum is where you do the lessons, the editor writes and runs code, AdvantageScope shows what the robot did, and Elastic is the drivers' dashboard
- Find your way around Scriptum: the menus, the **Verify** button, and how to ask **Dozer** for help
- Know the robot safety habits from the presentation before you go near a real robot: call “ENABLING!” and wait for “Clear!”, check the mode in the [Driver Station](../tools/driver-station.mdx) (never enable Autonomous with people around the robot), and read the robot signal light (blinking means enabled, so stay back).
- Create a [GitHub Account](https://github.com/signup?ref_cta=Sign+up&ref_loc=header+logged+out&ref_page=%2F&source=header-home) if you don't already have one.
- Join the [FRC Team 4143 GitHub Organization](https://github.com/FRC-Team-4143)
- Sign in to [Scriptum](https://scriptum.marswars.org) with your team account (read [Using Scriptum](../tools/scriptum.mdx) first) and complete the **Meet the Editor**, **AdvantageScope** and **Elastic** lessons. Scriptum is where you will do the rest of the training.
- The **Git Basics**, **Choreo** and **Arbor** lessons are also in Scriptum's Tools track, but they belong to later sessions: Choreo and Arbor to [Autonomous](./autonomous.mdx), and Git Basics to [Coding as a Team](./coding-as-a-team.mdx). Leave them until then.
