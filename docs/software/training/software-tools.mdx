# Software Tools
This is the first training module in our FRC programming series. It covers the software development tools you will use every time you program: the editor, git and GitHub, AdvantageScope and Elastic. It opens with a few minutes of robot safety.

:::note
This session does not cover robot hardware. The roboRIO, radio, motor controllers, the CAN bus and the tools that set them up start in the next session, [Motors and Drivetrains](./motors-drivetrains.mdx).
:::

## Exercises
- Know what each tool is for: the editor writes and runs code, git and GitHub save and share it, AdvantageScope shows what the robot did, and Elastic is the drivers' dashboard
- Know the robot safety habits from the presentation before you go near a real robot: call “ENABLING!” and wait for “Clear!”, check the mode in the [Driver Station](../tools/driver-station.mdx) (never enable Autonomous with people around the robot), and read the robot signal light (blinking means enabled, so stay back).
- Create a [GitHub Account](https://github.com/signup?ref_cta=Sign+up&ref_loc=header+logged+out&ref_page=%2F&source=header-home) if you don't already have one.
- Join the [FRC Team 4143 GitHub Organization](https://github.com/FRC-Team-4143)
- Sign in to [Scriptum](https://scriptum.marswars.org) with your team account (read [Using Scriptum](../tools/scriptum.mdx) first) and complete the **Meet the Editor**, **Git Basics**, **AdvantageScope** and **Elastic** lessons. Scriptum is where you will do the rest of the training.
- The **Choreo** and **Arbor** lessons are also in Scriptum's Tools track, but they are introduced in the [Autonomous](./autonomous.mdx) session. Leave them until then.
