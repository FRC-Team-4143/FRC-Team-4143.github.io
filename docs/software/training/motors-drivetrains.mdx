This is where the training meets the robot hardware. We start with how a command reaches a motor: the Driver Station, the radio, the roboRIO, the CAN bus and the motor controllers, and the tools that set CAN IDs. We look at the difference between a motor and its motor controller, and at motors like the Kraken and Falcon 500 that have the controller built in. Then we explore the various motors and drivetrains commonly used in FRC robots.
We will also write our first Java: reading a controller and driving a simulated differential drive robot through MWLib, the team's robot library, so we never program a motor directly.

:::note Building, deploying, and where main() went
**Building** checks your Java and turns it into a program the robot can run. A mistake, like a missing semicolon, stops the build, and the console names the file and line to fix. **Deploying** copies that built program onto the robot's roboRIO. In Scriptum, **Start** builds your code and runs it on the simulated robot, so there is nothing to deploy. On a real robot, **Deploy Robot Code** in WPILib VS Code (Shift+F5) builds and then deploys. See [Build Tools](../robot_dev/wpilib.mdx#build-tools).

The Java Basics lessons put your code inside `main()` in `Main.java`. A robot project still has a `Main.java`, but it has one line, `RobotBase.startRobot(Robot::new)`, which hands your `Robot` to WPILib. A robot program never ends, so WPILib keeps calling your methods, like `teleopPeriodic()` every 20 ms. Scriptum hides `Main.java` because you never change it. Your code goes in `Robot.java`.
:::

## Exercises
:::tip Plan it first
Before you type any Java, write the steps in plain English (pseudocode). For driving straight: read how far the left stick is pushed, flip it so up means forward, send that speed to both sides. Then turn each step into a line of code.
:::

### Motors
- Read the controller sticks from your own code
    - Declare `double` variables and store the stick values in them on the same line
    - Remember that pushing a stick forward gives a negative number
### Drivetrains
- Tank drive: the left stick drives the left side and the right stick drives the right side
    - Drive forward, backward, and spin in place
- Arcade drive: the left stick drives forward and backward (up/down) and turns (left/right)
    - Use arithmetic: `left = forward + turn` and `right = forward - turn`
- Bonus: add a speed limit, and try squaring the stick values for finer control
