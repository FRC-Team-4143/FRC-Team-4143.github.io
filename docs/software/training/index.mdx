# 📚 Training Materials

Welcome to the MARS/WARS Pre-Season Training Materials! This comprehensive curriculum is designed to help new and returning team members get up to speed with the software tools and practices used in FRC programming.

:::note
It is **highly recommended** to complete these lessons in order as they walk through the fundamentals step-by-step, building upon previous concepts.
:::

## The training path

Ten sessions take you from your first line of Java to a robot that drives and shoots by itself. You do
not need any programming experience: **each lesson teaches the Java it uses, right when it needs it.**

Most lessons are done in [Scriptum](https://scriptum.marswars.org), our browser-based robot IDE (see [Using Scriptum](../tools/scriptum.mdx)). Each lesson loads a project, a
README with the steps, and a simulated robot you drive from the Driver Station. The **Verify** button
checks your work. The slides on each lesson page introduce the ideas, and the exercises on the page match
the Scriptum lesson.

| # | Session | New Java | What the robot does |
|---|---------|----------|---------------------|
| 1 | [Hardware and Software Tools](./training/hardware-software-tools) | none (git and the tools) | Set up your accounts and learn the tools |
| 2 | [Motors and Drivetrains](./training/motors-drivetrains) | calling methods, variables, operators | Tank and arcade drive |
| 3 | [Sensors and Feedback](./training/sensors-feedback) | `if` / `else`, constants | Measure speed and distance, drive 2 m with bang-bang |
| 4 | [Drive Math and Methods](./training/drive-math-methods) | writing methods, arrays, `for` loops | Move the math into methods |
| 5 | [Objects and Odometry](./training/objects-odometry) | classes, objects, `static` | Know where the robot is (kinematics and pose) |
| 6 | [Mechanisms and Subsystems](./training/mechanisms-subsystems) | enums, `switch`, inheritance | Drivetrain and shooter subsystems |
| 7 | [Control Theory](./training/control-theory) | practice | Bang-bang, feedforward and PID for the flywheel |
| 8 | [State Machines and Commands](./training/state-machines-commands) | `&&` `||` `!`, lambdas | A shooter that spins up before it shoots |
| 9 | [Autonomous](./training/autonomous) | extending `Command`, `for` loops | Left, Right and Square autos |
| 10 | [Computer Vision](./training/computer-vision) | none | Train an object detector |
