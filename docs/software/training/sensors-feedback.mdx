## Exercises
### Sensors
- Convert the encoder readings (`getLeftPositionRad()`, `getRightPositionRad()`) from wheel radians to meters
    - meters = wheel radians * wheel radius (0.0762 m)
- Show chassis speeds in AdvantageScope
    - Linear speed in m/s (forward / backward)
    - Angular speed in rad/s (rotation)
- Show distance traveled by driving
    - Use encoders to measure distance
### Conditions
- Add a deadband so the robot ignores small stick drift
    - Declare a `DEADBAND` constant
    - Use an `if` statement on each stick to set small values to zero
### Feedback
- Implement a simple Bang Bang controller to drive 2 meters in autonomous
    - Use encoders to measure distance
    - Use an `if` / `else`: a constant speed until the robot reaches the target distance, then stop
    - Where does the robot actually stop? Why?
    - Run Auto a second time: resetting the encoders in `autonomousInit()` makes it start counting from zero again
