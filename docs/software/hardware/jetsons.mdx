# Nvidia Jetson Vision Computer

The Nvidia Jetson is an embedded computer used for vision processing in our FRC robots. It is responsible for
processing images from the cameras mounted on the robot and providing data to the RoboRio for autonomous actions. 
The Jetson runs an Ubuntu Linux-based operating system and runs our AprilTag detection software during matches. 
It also often runs other vision processing tasks such as game piece detection.

The software it runs is [Aquila Vision](https://github.com/coalman321/Aquila-Vision). See
[How Our Vision System Works](../vision/pipeline.mdx) for how it gets from a camera picture to a robot pose,
and [Setting Up the Cameras](../vision/camera-setup.mdx) for its camera web page at port 5800.
[Object Detection](../vision/obj_det.mdx) and [AprilTag Fiducials](../vision/april_tags.mdx) cover the
vision processing tasks themselves.

It can be accessed over SSH when connected to the robot's network.
